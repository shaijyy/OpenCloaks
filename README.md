# OpenCloaks
a fully open-source, self-hostable, community-driven, OptiFine-supported Minecraft cosmetics protocol.

in very early stages of development. PoC and API documentation is available on this very repo :)  
  
  
| Service | Directory |
| --------- | ---------- |
| Server | `/server` |
| MC Server | `/minecraft` |
| Website | `/website` |
| Management Panel | `/management` |
| Discord Bot | `/discord` |
| Documentation | `/docs` |
